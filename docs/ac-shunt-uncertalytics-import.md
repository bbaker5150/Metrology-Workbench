# AC shunt budget import

In the full Workbench, open Uncertalytics and choose the lightning button immediately after Unit converter. Search saved AC-shunt sessions by name, model or serial, select a session, review the preview, then create a new saved budget. Existing analysis sessions and calibration results are preserved. The standalone entry point does not import this tool or its API client.

The importer creates Electrical measurement points for each current/frequency pair, a UUT, and reference instruments from the saved session identity. A40B includes both TVCs and readers; Y5020 includes its readers and reference shunt. Repeated reader serials (or addresses when no serial is recorded) identify one physical instrument.

For repeat imports, share the completed instrument definitions in the Instrument Library first. Selecting a saved run automatically matches shared definitions by model and serial, including older imports that stored the serial in the Model field. The preview shows the matches; an optional selector resolves duplicate identities or differently named definitions. Local-only instruments are not automatically substituted. Each import creates a separate saved budget and leaves previous budgets and the shared masters unchanged.

Matched instruments keep their function/range IDs, uncertainties, distributions and qualifiers. Current or saved phase voltage and frequency select the corresponding range, including unit conversion (for example Hz to kHz). Reader AC and DC functions stay separate; a saved 5790B range is respected, while AUTO uses the smallest enclosing shared voltage range. Missing or overlapping matches remain incomplete instead of silently selecting the first range or rebuilding a manufacturer specification. The new run supplies its Type A results, points and saved transfer sensitivities. Certificate coverage-factor setup is hidden when all certificate instruments come from the shared library. Unmatched instruments retain the initial-setup generation path below.

Type A uses the existing read-only pair analytics: the session's ABBA choice, cycle cap, automatic rejection and manual exclusions all apply. The standard uncertainty is already s/sqrt(N); it is not divided again. Degrees of freedom are N−1. The paired AC/DC difference and source point IDs remain in each point's source metadata. A current nominal in A allows the budget to express both absolute current uncertainty and relative ppm.

For initial setup, shunt uncertainty comes from each point's linked RoC, with an explicitly flagged current-report fallback for legacy points. TVC uncertainty comes from the current report at the exact frequency, since historical TVC report IDs are not stored on calibration results. No certificate uncertainty interpolation is performed. The preview exposes the certificate coverage factor, initially 2, because the database does not store that factor. Missing data generates an incomplete budget row and prevents a misleading combined uncertainty. Shared definitions supply the uncertainties on subsequent imports; A40B still needs the TVC test voltage for transfer propagation.

Y5020 UUT acceptance uses the lab's requested **Navy ±100 ppm of reading** requirement at every imported point, with **no UUT bias**. For example, 10 A has a ±0.001 A acceptance tolerance. Manufacturer 250/350 ppm limits and the measured paired AC/DC difference are not applied to the Y5020 UUT. Older shared Y5020 definitions are adjusted only in the new budget's copy, preserving their range IDs and showing the local override; the reference shunt and shared master are unchanged. Already-correct shared definitions remain synchronized.

A40B retains its shared limits when matched. Initial setup uses manufacturer calibrated-current accuracy from the [A40B manual](https://assets.fluke.com/manuals/A40B____imeng0000.pdf), printed p.4: nominal shunt range, 1-year specifications, and prescribed linear interpolation above 1 kHz. Below 1 kHz the importer adopts the 1 kHz limit, explicitly recorded in the assumptions. Saved humidity above 50% adds the prescribed 20 ppm. These editable current-accuracy limits are not a claim that the manual specifies a separate AC/DC-transfer acceptance limit at every imported frequency.

New imports are native **derived measurement points**, with an editable equation, named inputs and individual input budgets. Each saved reader phase has its own voltage input; its accuracy, resolution and additional shared uncertainties link to the actual TMDE range in volts. The equation supplies the voltage-to-current sensitivity. The reference-shunt input carries its calibration uncertainty in equivalent amperes, not a signed correction or the UUT acceptance tolerance. A40B TVC calibration uncertainties have voltage inputs too. Physical ranges and instrument identities are reused across inputs. Editing a linked range refreshes every affected input, expanded uncertainty and risk. Deleting a linked instrument or physical range leaves an incomplete source instead of silently dropping its uncertainty or substituting another range. Existing imported budgets are preserved; import the saved run again to create the native derived version.

The importer calculates uncertainty immediately and checks TUR, PFA and PFR with the existing risk engine. TAR is unavailable under the native derived-budget rule when the TMDE specification limits and output use different physical units (volts and amperes). For Y5020, the paired AC/DC difference remains source metadata only. Generated A40B definitions retain the previous signed-UUT-bias behavior; it is not added to RSS. Default assumptions are 85% reliability, 12-month calibration interval, required TUR 4, PFA target 2%, and 95% coverage. The preview reports how many points have calculated risk and lists missing inputs. These assumptions and acceptance limits require review against the lab procedure.

Generated reader specifications use a 1-year calibration interval; shared readers retain their authored specifications. The 34420A 1 V range is ±(0.0035% reading + 0.0004% range), treated as a rectangular limit. The attached Agilent Service Guide, printed page 12 (PDF page 14), verifies this row. Its conditions include 100 NPLC, filters off, 23 ±5 °C and a 2-hour warm-up. Saved NPLC differences are flagged. See also the attached HP User's Guide, printed page 276 (PDF page 274); its older table has misaligned range labels, so the clearly aligned service-guide table controls the values.

5790B values use the supplied Service Manual, sections 1-6 through 1-8 and 1-12 (PDF pages 12–14 and 18): absolute **measurement-mode** voltage specifications, normal k=2.58. These match the [manufacturer extended specifications](https://s3.amazonaws.com/download.flukecal.com/pub/literature/6005014a-5790b-ext-specs-w.pdf). The importer respects the saved physical range; an explicit AUTO setting selects the smallest supported range containing the saved voltage. DC uses at least 220 mV. Thus 69 mV selects 70 mV and 200 mV selects 220 mV when AUTO was recorded. Unsupported ranges, missing settings, out-of-range voltages and unsupported reader models remain incomplete. Implemented AC ranges span 2.2 mV through 22 V and frequencies 10 Hz through 1 MHz. At common frequency endpoints the larger adjacent specification is used.

The editable equation uses `(Vac/Vdc − recordedRatio)/eta` for each reader and direction, with `Vac/Vdc = (V_ac_open + V_ac_close)/(abs(V_dc_pos) + abs(V_dc_neg))`. Imported input voltages are magnitudes. The output is `Iref + I0 * mean(reference term − UUT term)`, plus A40B TVC ratio deviations when applicable. `Iref` is nominal current with reference-shunt calibration uncertainty; `I0` is an exact nominal scaling input. Centering each ratio on its saved value preserves the nominal current and avoids reapplying the measured difference as implicit Y5020 bias. Editing an input subsequently changes the equation result normally. Type A is added once in the final current budget, outside the equation.

Repeated phases and directions from one physical reader use explicit, editable native input correlations. The initial conservative full-magnitude assumption uses +1 for equal-signed sensitivities and −1 for opposite-signed sensitivities, preventing presumed systematic cancellation or reduction from averaging. This is a conservative assumption, not measured covariance; review it in the correlation editor against the lab procedure. Separate physical readers are initially independent. Input accuracy and resolution combine through the normal input-budget rules before propagation. The assumptions, source URLs, raw specifications and phase values remain available for review. These are editable snapshots, not live links to later calibration-record changes.
