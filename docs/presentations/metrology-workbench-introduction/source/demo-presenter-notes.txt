1. Metrology Workbench

Metrology Workbench brings three complementary tools into one home screen. Run Calibration handles supported Y5020 and A40B calibration workflows. Uncertainty Budget carries saved Type A results into a wider analysis of measurement uncertainty and decision risk. Report of Calibration imports saved calibration results into an editable report. Users review instrument definitions, analysis assumptions and report metadata as part of their work. The architecture supports additional modules and calibration capabilities in the future.

2. Run Calibration

2. Run Calibration

The calibration workflow supports Y5020 and A40B shunts. A measurement session holds test points, instrument settings and cycle configuration. During a run, instrument status, stability and results provide visibility into measurement progress. Saved measurements and their statistical Type A uncertainty can support subsequent uncertainty analysis and reporting. Type A uncertainty is one contribution to an uncertainty budget, rather than the whole budget.

Suggested demonstration: open Run Calibration, show session setup, then show a saved result with its Type A uncertainty.

4. Uncertainty Budget

3. Uncertainty Budget

Import a saved shunt session to create a new Electrical budget with its measurement points and Type A results. Match instruments to shared definitions so specifications and ranges can be reused. Review Type B contributions and the resulting uncertainty budget. Risk calculations include test uncertainty ratio, probability of false acceptance and probability of false rejection where the required input data are available. Guardband analysis explores acceptance limits against configured risk requirements. Review import warnings and instrument definitions before relying on results.

Suggested demonstration: import a completed calibration, inspect contributors at one test point, then compare risk and guardband results.

6. Report of Calibration

4. Report of Calibration

Pull a completed calibration into an editable Report of Calibration. The current import maps instrument identity, environmental data and measurement results, including the stored expanded uncertainty and coverage factor, into the report. Review the uncertainty basis and complete customer, procedure, dates and personnel details as needed. Organize report sections and supporting statements, inspect the preview, then export a PDF or Excel workbook. Generation supports the reporting workflow; it does not replace technical review or approval.

Suggested demonstration: select a saved session, show the imported measurement table, complete metadata, and open the report preview.
